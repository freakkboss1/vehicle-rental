# Система аренды транспортных средств (Vehicle Rental System)

Консольное приложение на языке Java для управления арендой транспортных средств.

## Назначение приложения
Приложение предназначено для учета автомобилей и мотоциклов, оформления их аренды клиентами, расчета итоговой стоимости с учетом типа транспорта, а также ведения отчетности по выручке. Данные сохраняются в файл и автоматически загружаются при повторном запуске программы.

## Реализованные возможности
- **Добавление ТС**: регистрация автомобилей и мотоциклов в системе.
- **Просмотр базы**: вывод списка всех транспортных средств или только доступных для аренды.
- **Оформление аренды**: аренда ТС на заданное количество дней с автоматическим расчетом стоимости.
- **Возврат ТС**: освобождение транспортного средства (изменение статуса на «доступен»).
- **Бизнес-правила**: 
  - Запрет на аренду уже занятого транспортного средства (выбрасывается собственное исключение `VehicleNotAvailableException`).
  - Проверка корректности вводимых данных (например, ставка аренды должна быть больше нуля).
- **Аналитика**: просмотр истории аренд и расчет общей выручки.
- **Сохранение данных**: использование сериализации Java (`Serializable`) для сохранения и загрузки базы ТС из файлов при выходе и запуске.
- **Консольный интерфейс**: удобное текстовое меню для навигации по функциям.

## Архитектура и структура проекта
Проект разделен на слои для соблюдения принципов SOLID и чистоты кода:
- `model/` — объектная модель предметной области (абстрактный класс `Vehicle`, наследники `Car` и `Motorcycle`, класс `Rental`, интерфейс `Rentable`).
- `service/` — бизнес-логика приложения. Содержит обобщенный (generics) класс `Repository<T>` для хранения коллекций и класс `RentalService` с логикой аренды.
- `io/` — слой работы с файлами (`FileStorage`). Отвечает за сохранение и загрузку данных через `ObjectInputStream` и `ObjectOutputStream`.
- `ui/` — пользовательский интерфейс (`ConsoleMenu`). Отвечает за вывод меню и чтение ввода пользователя.
- `exception/` — собственные классы исключений (`VehicleNotAvailableException`).
- `Main.java` — точка входа в программу.
